Every hole is

A breadboard looks like a grid of identical holes. It isn't — underneath, strips of metal decide which holes are electrically the same point and which are strangers. This guide is that wiring, made visible.

Hover any hole below — everything that lights up shares one electrical node.

01 — Layout

Four parts, one grid

Every full-size breadboard is built from the same four structures. Learn these once and every board you'll ever touch reads the same way.

POWER RAILS

The red and blue lines

Two strips run along the top and bottom, each split into a + row and a − row. Every hole along a rail is connected — but the + and − rows are never connected to each other.

TERMINAL STRIPS

The main working field

Each column of five holes (A–E or F–J) is one node. Plug two legs into the same column and they're joined; plug them into different columns and they're not.

CENTER GAP

The dividing trench

The channel down the middle physically and electrically separates the top half (F–J) from the bottom half (A–E). It exists so DIP chips can straddle it without shorting their own pins.

RAIL BREAKS

Not always one long wire

On larger boards the power rails are often split at the midpoint, sometimes with a visible break in the printed line. Check continuity — don't assume the whole rail is one node.

02 — Failure Modes

Where the smoke gets out

Almost every "my circuit doesn't work" is one of these four, in order of how often they actually happen.

!

Straddling the gap by accident

A resistor placed across the center channel connects two unrelated halves of the board. Sometimes that's intentional — usually it's a short you didn't mean to build.

!

Assuming the rails are joined

The + and − rails sit right next to each other but carry no connection between them. Power still needs a component — a resistor, an LED, anything — to bridge them.

!

A half-seated wire

A jumper that looks plugged in but isn't fully seated makes an intermittent connection — the classic "it worked when I touched it" bug.

!

Miscounting the column

Rows A–E in a column are one node, F–J in that same column are a separate one. Reading straight across the gap as "still connected" is the single most common wiring error.

03 — Worked Example

Build one: an LED test circuit

The smallest circuit that proves a board is wired correctly. Five components, one loop, nothing that can't be undone in ten seconds.

+ rail − rail resistor LED + jumper
  1. Run a jumper from the board's + rail to any row on the terminal strip, say column 12.
  2. Place a 220Ω resistor from that same column 12 into a fresh column, 14.
  3. Seat the LED's long leg (anode) into column 14 — same node as the resistor's other end.
  4. Seat the LED's short leg (cathode) into a new column, 16.
  5. Jumper column 16 back to the − rail to close the loop.
  6. Connect the rails to a 5V source. The resistor limits current so the LED lights instead of burning out.

05 — Next Step

When to graduate off the breadboard

A breadboard is for proving an idea works. It's not the last stop — here's what changes as a circuit gets more permanent.

BREADBOARD

Prove it works

No soldering, fully reusable, connections can loosen over time. Best for prototyping and testing — not for anything that needs to survive being carried around.

PERFBOARD

Make it permanent

Same hole-grid layout, but you solder each connection by hand with wire underneath. Cheap and durable, though rewiring means desoldering.

PCB

Make it repeatable

Copper traces are etched into the board itself, so every connection is fixed at design time. The standard for a finished project or anything built more than once.

06 — Quick Reference

The cheat sheet

SAME COLUMN
Rows A–E in one column are one electrical node. Same for F–J in one column.
ACROSS THE GAP
The center channel breaks the connection — a column's top half and bottom half are separate nodes.
POWER RAILS
Each rail row is one long node end-to-end (or in two halves on larger boards) — but + and − never touch.
DIP CHIPS
Straddle the center gap so each row of pins lands in its own half, keeping every pin on a separate node.
CURRENT-LIMITING
Never wire an LED straight across a rail — pair it with a resistor (220Ω–330Ω is a safe default at 5V) every time.
BEFORE POWERING ON
Trace the loop with your finger: source → component → component → back to source. If it doesn't close, it won't work.
